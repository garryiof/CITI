# Pass W — Workflow grouping

Group the extracted actions into the distinct workflows a reader would follow (for example: request pre-approval, disclose accounts, report a violation).
Use only the action labels provided, copied exactly. Each action may appear in more than one workflow; keep each workflow's labels in execution order.
Give every workflow a short title, a one-sentence summary and the trigger that starts it, all grounded in the action descriptions.
Do not invent actions, workflows, or steps that are not supported by the provided actions.
